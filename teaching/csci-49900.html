Course/Project Description

This course is a chance for Computer Science majors to test their mettle on major projects. Working in small groups of 3-5 people, you will implement systems that involve at least two different programming languages and a combination of multiple of the following features:

  1. Integration with a 3rd Party API: Implement and effectively utilize a third-party API to enhance the functionality or data integration of the project.
  2. Substantial Security Features: Incorporate advanced security measures such as encryption, two-factor authentication (2FA), and token-based authentication to protect user data and ensure application integrity.
  3. Graphics Implementation: Develop and integrate advanced graphical components or visualizations, which could include custom UI elements, data visualizations, or interactive animations.
  4. Needfinding and User Interviews: Conduct needfinding interviews with potential users or stakeholders, followed by a structured synthesis of insights to inform and guide the project development process.
  5. Customized AI/ML Neural Network: Design and implement a custom artificial intelligence or machine learning neural network that is tailored to solve a specific problem or add intelligent features to the application.
  6. Cloud Infrastructure Deployment: Design and deploy the project using cloud infrastructure, ensuring scalability, reliability, and efficient resource management. This could include using services like AWS, Azure, or Google Cloud for hosting, storage, or computing power.
  7. DevOps and CI/CD Pipeline: Set up a Continuous Integration/Continuous Deployment (CI/CD) pipeline to automate testing, integration, and deployment processes. Utilize tools such as Jenkins, GitLab CI, or GitHub Actions.
  8. Custom API Development: Design and implement a custom Application Programming Interface (API) tailored to your project’s needs. The API should allow external applications or services to interact with your system, providing well-defined endpoints, data formats, and authentication mechanisms.
  9. Data Handling and Storage: Design and implement efficient data storage solutions using SQL or NoSQL databases. Consider aspects such as indexing, data migration, and backup strategies.
  10. Performance Optimization: Focus on improving the speed and efficiency of the application through various techniques, such as code optimization, caching strategies, or load balancing.
  11. Augmented Reality (AR) or Virtual Reality (VR) Components: Develop and incorporate AR or VR features into the application, providing an immersive user experience.
  12. Blockchain Integration: Utilize blockchain technology for a specific aspect of the project, such as secure transactions, decentralized storage, or smart contracts.
  13. Ethical Considerations and Impact Analysis: Analyze and address the ethical implications of the project, considering aspects such as data privacy, algorithmic bias, and accessibility. Provide a detailed report on the findings.
  14. Accessibility Features: Ensure that the application is accessible to users with disabilities, implementing features such as screen reader support, keyboard navigation, and color contrast adjustments.
  15. Data Analytics and Visualization: Implement data analytics features, allowing users to gain insights from the data through interactive visualizations, dashboards, or reports.

Prerequisites

All non-elective courses in Computer Science required for graduation or permission of instructor.

Course Objectives

Upon successful completion of this course, students will have collaboratively completed a senior capstone project in groups of 3-5 members. Each project will utilize at least two different programming languages and incorporate a variety of additional features that demonstrate the students’ technical proficiency and creativity.

By the end of the course, students will have developed a substantial project that showcases their individual strengths while fostering collaboration and the acquisition of new development skills. In addition to technical development, students will produce comprehensive documentation to ensure that their platform is accessible and usable by others.

Furthermore, students will enhance their oral presentation skills through the preparation and delivery of project presentations, enabling them to effectively communicate their work to both technical and non-technical audiences.

Grading

Grades will be based on a project, presentations, attendance, etc. You will work with a team of 3 to 5 other students. This grade will be determined in part by my evaluation of the project and in part by your team members evaluation of your contribution. Periodic presentations and written reports, reporting on tools and progress, will account for the majority of your grade.
